# `backend/db/db.js` 파일 분석

## 1. 파일의 역할

`db.js` 파일은 MongoDB 데이터베이스와의 **연결을 설정하고 관리**하는 역할을 합니다. Mongoose 라이브러리를 사용하여 Node.js 애플리케이션과 MongoDB 인스턴스 간의 연결을 수립하며, 연결 상태를 모니터링하고 연결 해제 기능을 제공합니다.

이 파일은 애플리케이션의 다른 부분에서 데이터베이스 연결 로직을 추상화하여, 데이터베이스 관련 설정 변경이 필요할 때 이 파일만 수정하면 되도록 합니다.

## 2. 주요 로직 및 구조

### `connectDB()` 함수

애플리케이션이 시작될 때 호출되어 데이터베이스 연결을 시도하는 비동기 함수입니다.

-   **환경 변수 로드**: `dotenv`를 사용하여 `.env` 파일에 정의된 환경 변수를 로드합니다. 특히 `MONGO_URI` 변수를 사용하여 MongoDB 연결 문자열을 가져옵니다.
-   **Mongoose 연결**:
    -   `mongoose.connect(process.env.MONGO_URI)`: Mongoose의 `connect` 메서드를 사용하여 MongoDB에 연결을 시도합니다. `MONGO_URI`는 MongoDB 서버의 주소와 데이터베이스 이름을 포함합니다 (예: `mongodb://localhost:27017/budget-meal-finder`).
    -   `useNewUrlParser: true`, `useUnifiedTopology: true`: Mongoose 6.x 버전부터는 기본값이 되었지만, 이전 버전과의 호환성을 위해 명시적으로 설정하는 경우가 많습니다. 새로운 URL 파서와 통합된 토폴로지 엔진을 사용하도록 합니다.
-   **연결 성공/실패 처리**:
    -   연결에 성공하면, `console.log`를 통해 성공 메시지와 함께 연결된 호스트 정보를 출력합니다.
    -   연결에 실패하면, `console.error`를 통해 에러 메시지를 출력하고 `process.exit(1)`을 호출하여 애플리케이션을 종료합니다. 이는 데이터베이스 연결 없이는 애플리케이션이 정상적으로 동작할 수 없다고 판단하기 때문입니다.

### `disconnectDB()` 함수 (주석 처리됨)

현재는 주석 처리되어 있지만, 데이터베이스 연결을 명시적으로 해제하는 `disconnectDB` 함수도 정의되어 있습니다.

-   **`mongoose.disconnect()`**: Mongoose 연결을 해제합니다.
-   **사용처**: 주로 애플리케이션 종료 시 또는 테스트 환경에서 각 테스트 케이스 후에 데이터베이스 연결을 정리할 때 사용될 수 있습니다.

## 3. 핵심 기술 및 패턴

-   **환경 변수 관리**: `dotenv`를 사용하여 민감한 정보(데이터베이스 URI)를 코드 외부에 분리하여 관리합니다. 이는 보안 및 환경별 설정 유연성을 높입니다.
-   **비동기 처리**: `async/await` 패턴을 사용하여 데이터베이스 연결과 같은 비동기 작업을 동기적인 코드처럼 읽기 쉽게 처리합니다.
-   **단일 책임 원칙 (Single Responsibility Principle)**: 이 파일은 오직 데이터베이스 연결이라는 한 가지 책임만 가집니다.

## 4. 다른 파일과의 상호작용

-   **`server.js`**: 애플리케이션의 메인 진입점인 `server.js`에서 `connectDB()` 함수를 임포트하여 호출함으로써 데이터베이스 연결을 초기화합니다.
-   **`.env`**: `MONGO_URI` 환경 변수를 통해 데이터베이스 연결 정보를 가져옵니다.
-   **`mongoose`**: MongoDB와의 상호작용을 위한 ODM(Object Data Mapping) 라이브러리입니다.
