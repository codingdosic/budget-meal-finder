# `backend/server.js` 파일 분석

## 1. 파일의 역할

`server.js`는 **Budget Meal Finder** 백엔드 애플리케이션의 **메인 진입점(Entry Point)**입니다. Express 프레임워크를 사용하여 웹 서버를 설정하고, 필요한 미들웨어를 등록하며, API 라우트를 정의하고, 데이터베이스 연결을 초기화하는 등 애플리케이션의 구동에 필요한 핵심 작업을 수행합니다.

## 2. 주요 로직 및 흐름

서버는 다음 순서로 실행됩니다.

1.  **환경 변수 로드**: `dotenv` 모듈을 사용하여 `.env` 파일에 정의된 환경 변수(예: 데이터베이스 연결 정보, 서버 포트 등)를 `process.env` 객체로 불러옵니다.
2.  **모듈 임포트**: `express`, `path` 등 핵심 모듈과 함께, 라우팅을 처리할 `*Routes.js` 파일들, 데이터베이스 연결을 위한 `db.js`, 에러 처리를 위한 `errorHandler.js` 등 프로젝트 내부 모듈들을 가져옵니다.
3.  **Express 앱 초기화**: `const app = express();` 코드를 통해 Express 애플리케이션 인스턴스를 생성합니다.
4.  **데이터베이스 연결**: `connectDB()` 함수를 호출하여 MongoDB 데이터베이스에 연결합니다.
5.  **미들웨어 등록**:
    *   `express.json()`: 클라이언트가 전송하는 JSON 형식의 요청 본문(body)을 파싱하여 `req.body` 객체에서 사용할 수 있도록 합니다.
    *   `express.static()`: 정적 파일을 제공하는 미들웨어입니다.
        *   `uploads` 폴더의 파일들을 `/uploads` 경로를 통해 제공합니다. (예: 사용자가 업로드한 이미지)
        *   `frontend` 폴더의 모든 파일(HTML, CSS, JS)을 제공하여 클라이언트 사이드 애플리케이션을 서비스합니다.
6.  **기본 페이지 라우팅**:
    *   루트 경로(`'/'`) 요청 시 `frontend/views/index.html` 파일을 응답으로 보냅니다.
    *   `'/find-credentials'` 경로 요청 시 `frontend/views/find-credentials.html` 파일을 보냅니다.
7.  **API 라우트 연결**:
    *   `app.use()`를 사용하여 특정 경로의 API 요청을 해당 라우터 모듈로 전달합니다.
    *   예를 들어, `/api/auth`로 시작하는 모든 요청은 `authRoutes` 모듈이 처리하게 됩니다. 이를 통해 라우팅 로직을 기능별로 모듈화하여 관리합니다.
8.  **중앙 에러 처리**: 모든 라우트 및 미들웨어 뒤에 `errorHandler`를 등록하여, 애플리케이션 전역에서 발생하는 오류를 일관된 방식으로 처리합니다.
9.  **서버 실행**: `process.env.PORT` 또는 기본값 `3000`번 포트에서 서버를 실행하고, 실행 성공 시 콘솔에 메시지를 출력합니다.

## 3. 다른 파일과의 상호작용

-   **`.env`**: 데이터베이스 URI, 포트 번호, JWT 시크릿 키 등 민감하거나 환경에 따라 달라지는 설정 정보를 가져옵니다.
-   **`./db/db.js`**: `connectDB` 함수를 호출하여 데이터베이스 연결을 수행합니다.
-   **`./routes/*.js`**: 인증, 식당, 메뉴 등 각 기능별 API 엔드포인트를 정의한 라우터 파일들을 임포트하여 API 요청을 위임합니다.
-   **`./middleware/errorHandler.js`**: 애플리케이션 전반의 오류를 처리하기 위한 중앙 에러 핸들러를 사용합니다.
-   **`../frontend/**`**: 웹 애플리케이션의 프론트엔드 리소스(HTML, CSS, JavaScript)를 정적 파일로 제공합니다.
-   **`../uploads/**`**: 사용자가 업로드한 이미지 파일 등을 정적 파일로 제공합니다.
